* Remove the temporary GPUI Base source override after selecting an upstream fixed release. External consumers must apply the same Cargo patch in their own workspace until then; see the getting started guide.
* The 22 story set is the initial demonstrated coverage. Dedicated stories for advanced DataTable, Tree, charts, code editing, docking and other upstream catalog systems remain future work. The underlying modules are re-exported; no duplicate implementation was introduced.
* Persistent window/panel storage, docking presets, advanced theme editing, custom fullscreen commands, signed/notarized installers and registry publication are deferred. Native platform window fullscreen controls remain available.
* Registry names and a real repository URL must be verified before publication. Full dependent-crate publish dry runs require lower level versions in the registry. No public Git tag exists yet.
* The primary color editor validates format and schema but does not guarantee an accessible color pairing. Verify contrast for application-specific themes. Upstream legacy theme storage limits detailed scale propagation as recorded in compatibility.md.

Recommended next work: replace the temporary override when a fixed upstream release is available; execute the three platform CI jobs and native platform passes; then extend stories according to actual consumer needs and resolve upstream maintenance warnings before a public release.
