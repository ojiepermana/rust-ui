# Icon assets

The 13 original, selectively included SVGs live in crates/ui-icons/assets so Cargo packages are self contained. Registration, validation and licensing are documented in docs/icons/README.md. No large external pack is copied here.

LICENSE-LUCIDE retains the ISC notice for the default icon assets supplied by the upstream component dependency. It does not change the Apache-2.0 license of this repository's original semantic icons.
