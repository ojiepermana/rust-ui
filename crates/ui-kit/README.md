# ui-kit

Import `ui_kit::prelude::*` and `ui_kit::gpui`. Initialize `gpui::init(cx)`, then `ThemeService::init(cx)`, before opening a window using `gpui::open_window`. For action derive macros also import `use ui_kit::gpui as gpui_kit;`.

Part of the Rust UI Kit workspace. Version 0.1.0, Apache-2.0. Native platform requirements and complete consumer examples are in the repository README. The package name is provisional for future registry publication.
