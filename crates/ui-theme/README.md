# ui-theme

Start with `ThemeRegistry::built_in()`, validate custom JSON through `ThemeDefinition::from_json`, then use `ThemeService` to register and apply definitions. Theme::update synchronizes native components. Detailed scales remain in the resolved snapshot.

Part of the Rust UI Kit workspace. Version 0.1.0, Apache-2.0. Native platform requirements and complete consumer examples are in the repository README. The package name is provisional for future registry publication.
